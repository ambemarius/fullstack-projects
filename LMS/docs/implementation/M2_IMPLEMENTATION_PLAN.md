No schema migration, live router/policy change or process restart. Rollback: leave staged router unmounted; no data undo required. API response deliberately excludes credentials, contact/medical/HR information and actual marks. Evidence is bounded; oversized results fail rather than silently misclassify a truncated set. Historical truth requires source records or explicit owner review. Authorization to implement M2 does not establish missing dates, historical classes, teacher years or coefficient policy. These unknowns do not block building the ledger and review workflow; they block automatic certification/backfill of affected records. Production migration approval must cover concrete reviewed SQL and rehearsal evidence, as required by the master plan.
